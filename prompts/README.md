# Ask an assistant to help

Copy one prompt at a time into your coding assistant while this repository is
open. Answer account/password prompts directly on the TV or the service's own
site. Do not paste passwords, tokens, pairing codes, home addresses or personal
photos into a public conversation.

## Build and try the demo

> Help me build and try Ambient TV from this repository. Read AGENTS.md and the
> setup guide. First check my Java and Android tools, then build the app, run tests
> and lint, and run the public-file check. Explain unfamiliar terms in plain
> language. Use an emulator first where possible. Do not control a real TV until
> I identify it and say it is free. Do not change my default launcher, clear data
> or remove apps. Show me the demo with the bundled scenery and report exactly
> what was verified.

## Connect my photo collection

> Help me connect Ambient TV to my Synology Photos Personal Space using the exact
> person name I enter on the TV. Walk me through the connection settings. Keep
> credentials and addresses out of chat and Git. Use an independent app login;
> never extract another app's session. Confirm that the selected person is unique,
> that both recent photos and older memories are available, and that an offline
> failure keeps the last complete cache. Do not modify or delete anything on my NAS.

## Make it my Home screen

> Help me make Ambient TV my Home app on this TV. Start by reading the current
> model, Android version and default Home app while the TV is free. Prefer the
> system's default-app setting. Keep the original launcher installed and give me
> a clear way to return to it. If the firmware blocks Home replacement, explain
> that before making further changes. Do not disable system apps or change Cast,
> Google Home, Assistant, network services, existing accounts or TV inputs. Test
> the physical Home and Back buttons and tell me which behavior I must confirm.

## Check Continue Watching

> Diagnose why a recent item is missing or stale in Ambient TV. Check the Home
> refresh and the source app separately. For Plex, preserve the profile authorized
> for Ambient TV and compare real server progress and next-episode records. For
> YouTube, compare its published Android TV feed with what I see in native History.
> Do not infer missing progress or guess a next episode. Do not play, finish or
> mark anything watched without my instruction. Keep findings redacted and explain
> which part is fixed, unverified or outside Ambient TV's control.

## Personalize the design

> Help me personalize Ambient TV while keeping the current navigation and data
> boundaries. Show a small change using bundled scenery first. Preserve aspect
> ratios, readable text, remote focus, the audio screensaver guard and bounded
> bitmap memory. Follow the TV's time zone. Keep weather opt-in and do not add
> analytics, a cloud backend or new tracking permissions. Run relevant tests and
> show an honest demo image before offering a TV install.

## Prepare my fork for public sharing

> Prepare this fork for public sharing. Start from an allowlist of source and
> demo assets; keep original device files and history private. Review source,
> comments, tests, documentation, images and Git metadata for personal details,
> addresses, credentials and signing material. Use generated scenery for all
> screenshots and check image metadata. Run the build, tests, lint, public-file
> check and a secret scanner over all commits. Use a public-safe author identity.
> Explain the limitations of automated scans. Publish only after resolving actual
> findings. Never copy my TV's private cache or an authenticated device backup.
