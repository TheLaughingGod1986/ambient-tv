# Report a security problem

Do not post credentials, tokens, private photos or an exploitable security issue
in a public issue. Use GitHub's **Security → Report a vulnerability** if that option
is available. If it is unavailable, open a public issue asking the maintainers to
enable private reporting, without including exploit details or personal data.

This is an experimental community app. There is no guaranteed response time.
See [privacy and permissions](docs/PRIVACY.md) for its data flows and limitations.
