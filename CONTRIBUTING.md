# Help improve Ambient TV

Start with [the development guide](docs/DEVELOPMENT.md). Small fixes, clearer
instructions and tests on more TVs are welcome. Explain the problem, the change
and how you checked it. Include Android version and TV model when relevant.

Use demo scenery in examples. Keep account data, addresses, private photos and
signing keys out of issues, logs and commits. Run the build, tests, lint and public
file check before submitting a change. Screenshots should identify whether they
come from an emulator, a TV or a design illustration.

The app and API code use Apache 2.0; retain third-party notices. Contributions are
provided under the repository's license. Keep discussion constructive and kind.
